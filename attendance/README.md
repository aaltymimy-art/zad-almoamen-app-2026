# إعداد قاعدة بيانات ملتقى العلم والدين

هذا الفرع يحافظ على تطبيق زاد المؤمن دون تعديل ملفاته. كما أبقينا نموذج `attendance/index.html` التجريبي كما هو؛ فهو لا يزال يحفظ محلياً فقط.

## ما تم تجهيزه
- مخطط قاعدة بيانات في `supabase/schema.sql`.
- جدول التسجيلات: الرابطة (1–10)، الاسم، العمر، الهاتف، وصف الملف/العمل داخل الرابطة، وتاريخ التسجيل.
- حماية RLS: الزائر يستطيع الإرسال فقط ولا يستطيع قراءة السجلات؛ القراءة متاحة لحسابات الإدارة المضافة يدوياً إلى `admin_users`.
- لا توجد مفاتيح أو كلمات مرور أو بيانات أعضاء داخل المستودع.

## المطلوب لتفعيل الربط الحقيقي
1. أنشئ مشروعاً جديداً في Supabase.
2. افتح SQL Editor ونفّذ محتوى `supabase/schema.sql`.
3. من إعدادات المشروع انسخ Project URL وPublishable/anon key (لا ترسل Service Role key أبداً).
4. أنشئ مستخدم إدارة من Authentication، ثم أضف UUID الخاص به إلى `public.admin_users` من SQL Editor.
5. زوّدني بـ Project URL وPublishable/anon key فقط، أو أدخلهما بنفسك في إعدادات الواجهة عند إكمالها. لا ترسل كلمة مرور حسابك.

## تنبيه
لم يتم بعد ربط نموذج الويب بهذه القاعدة أو إنشاء لوحة الإدارة أو نشر نسخة فعالة؛ لا تستخدم النموذج الحالي لجمع بيانات حقيقية. هذا الفرع إعداد آمن أولي قابل للمراجعة، وليس إطلاقاً نهائياً.
