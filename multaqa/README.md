# ملتقى العلم والدين

المشروع موجود في الفرع المستقل `multaqa-alilm-waldeen` داخل المستودع. لم يتم تعديل فرع `main` أو ملفات تطبيق زاد المؤمن.

## الملفات
- `multaqa/index.html`: واجهة التسجيل العربية، بسبع روابط ولوحة إدارة.
- `multaqa/assets/logos-sprite.jpg`: صورة الشعارات السبعة المستخدمة في بطاقات الروابط.
- `multaqa/schema.sql`: جداول قاعدة البيانات وسياسات أمان RLS.
- `.github/workflows/deploy-multaqa.yml`: سير عمل نشر GitHub Pages من مجلد multaqa.

## وظائف الواجهة الموجودة في الكود
- استمارة الاسم الكامل والعمر ورقم الهاتف والملف داخل الرابطة.
- لوحة إدارة عبر Supabase Auth.
- إحصائية إجمالية ولكل رابطة.
- بحث وتصفية وتعديل وحذف.
- تصدير CSV متوافق مع Excel ويدعم العربية.

## ما يلزم قبل استقبال تسجيلات حقيقية
تم إدخال Project URL ومفتاح Publishable العام في الواجهة. لكن الاتصال الفعلي لا يكتمل قبل تشغيل مخطط SQL أدناه واختبار الصلاحيات والنشر.

1. أنشئ مشروعاً في Supabase.
2. افتح SQL Editor وشغّل محتويات `multaqa/schema.sql`.
3. تم إعداد Project URL ومفتاح `sb_publishable_` في أعلى `multaqa/index.html` لهذا المشروع. لا تستبدلهما إلا عند تغيير مشروع Supabase.
4. لا تضع Service Role Key في الواجهة مطلقاً.
5. أنشئ حساب مدير من Authentication > Users.
6. أضف UUID حساب المدير إلى جدول `public.admins` من SQL Editor:
   `insert into public.admins (user_id) values ('UUID-OF-ADMIN');`
7. اختبر إرسال تسجيل كزائر، ثم الدخول بحساب المدير، والبحث والتعديل والحذف والتصدير.

## إعداد النشر على GitHub Pages
ملف النشر موجود ويعمل عند الدفع إلى فرع `multaqa-alilm-waldeen)، بشرط تفعيل GitHub Pages:
1. افتح Settings > Pages في المستودع.
2. اختر GitHub Actions كمصدر للنشر.
3. افتح Actions وتابع تشغيل Deploy Multaqa site.
4. بعد نجاح النشر سيظهر رابط الموقع ضمن تشغيل المهمة.

## الأمان والحالة
- سياسات RLS تسمح للزائر بإضافة تسجيل فقط، ولا تسمح له بقراءة بيانات الأعضاء.
- القراءة والتعديل والحذف متاحة لحسابات Auth التي يضاف UUID الخاص بها إلى جدول admins.
- أسماء الروابط في الواجهة مؤقتة: الرابطة 1 إلى الرابطة 7؛ يمكن استبدالها بالأسماء الرسمية لاحقاً.
- تم ربط الشعارات السبعة بالبطاقات.
- لا يوجد رابط حي مؤكد حتى يتم تفعيل GitHub Pages وإكمال إعداد Supabase.
