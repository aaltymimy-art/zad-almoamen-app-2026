# ملتقى العلم والدين

المشروع موجود في الفرع المستقل `multaqa-alilm-waldeen` داخل المستودع. لم يتم تعديل فرع `main` أو ملفات تطبيق زاد المؤمن.

## الملفات
- `index.html`: واجهة التسجيل العربية بعشر روابط، واستقبال طلبات التسجيل عبر Supabase بعد ضبط بيانات الاتصال.
- `schema.sql`: جداول قاعدة البيانات وسياسات أمان RLS.
  
## ما أصبح جاهزاً
- استمارة الاسم الكامل والعمر ورقم الهاتف والملف داخل الرابطة.
- لوحة إدارة بتسجيل دخول Supabase Auth.
- إحصائية إجمالية ولكل رابطة.
- بحث وتصفية، تعديل وحذف.
- تصدير ملف CSV متوافق مع Excel (مع ترميز UTF-8 العربي).

## ما يحتاج إعداداً قبل استقبال بيانات حقيقية
1. إنشاء مشروع Supabase.
2. فتح SQL Editor وتشغيل محتويات `schema.sql`.
3. من إعدادات المشروع نسخ Project URL و anon/public key ووضعهما في أعلى ملف `index.html` مكان النصين التوضيحيين. لا تضع Service Role Key في الواجهة مطلقاً.
4. إنشاء حساب مدير من Authentication > Users في Supabase.
5. إضافة UUID لحساب المدير إلى جدول `public.admins` من SQL Editor:
   `insert into public.admins (user_id) values ('UUID-OF-ADMIN');`
6. نشر مجلد `multaqa` على استضافة HTTPS. رابط GitHub لعرض الملف ليس رابط تشغيل الموقع.

## ملاحظات أمان
- سياسات RLS تسمح للزائر بإضافة تسجيل فقط، ولا تسمح له بقراءة بيانات الأعضاء.
- القراءة والتعديل والحذف متاحة لحسابات Auth التي يضاف UUID الخاص بها إلى جدول admins.
- اختبر الصلاحيات بحساب زائر وحساب مدير قبل إطلاق التسجيل العام.
- أسماء الروابط حالياً مؤقتة (الرابطة 1 إلى الرابطة 10) إلى أن تُزوّدنا المؤسسة بأسمائها وشعارها الرسمي.
