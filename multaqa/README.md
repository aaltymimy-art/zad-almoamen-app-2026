# ملتقى العلم والدين

هذا المشروع موجود في فرع مستقل باسم `multaqa-alilm-waldeen` داخل المستودع، ولم يتم تعديل فرع `main` أو ملفات تطبيق زاد المؤمن.

## الملفات
- `multaqa/index.html`: واجهة أولية متجاوبة باللغة العربية، تتضمن عشر بطاقات للروابط واستمارة التسجيل المطلوبة.

## الحالة الحالية
هذه واجهة أولية فقط. لم يتم بعد ربطها بقاعدة بيانات مركزية أو إعداد تسجيل دخول إداري آمن أو تصدير Excel. لا تستخدمها لجمع بيانات حقيقية إلى حين إكمال هذه الأجزاء.

## المطلوب للإكمال
1. تثبيت أسماء الروابط العشر وشعار المؤسسة.
2. إعداد قاعدة بيانات وخدمة خلفية آمنة لحفظ التسجيلات مركزياً.
3. بناء لوحة إدارة محمية بالصلاحيات، مع البحث والتعديل والحذف والإحصائيات وتصدير Excel.
4. إعداد النشر الدائم وربط الدومين/رابط الموقع.
